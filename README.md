# 飞机大战 (Plane Shooter)

纯 HTML5 Canvas 竖版飞机射击小游戏，无需构建工具。

## 如何运行

在项目目录下启动任意静态服务器：

```bash
cd /workspace/plane-shooter

# 方式一：Python
python -m http.server 8765

# 方式二：npx serve
npx serve -p 8765
```

然后在浏览器打开：

```
http://localhost:8765/
```

也可直接用浏览器打开 `index.html`（部分浏览器对本地文件限制音频自动解锁，建议用静态服务器）。

## 操作说明

| 平台 | 移动 | 射击 |
|------|------|------|
| 桌面 | WASD / 方向键 | 自动射击（也可按空格） |
| 手机 / 触屏 | 拖动飞机 | 自动射击 |

- **M** 键或 HUD 上的按钮：静音 / 取消静音
- 首次点击或按键会解锁 Web Audio（移动端必需）

## 功能一览

- 分数、生命、渐进难度
- 多种敌机（侦察 / 战斗机 / 轰炸机 / 精英）
- 道具：连射（R）、护盾（S）
- 游戏结束与「再来一局」
- 星空背景、粒子爆炸、屏幕震动
- Web Audio API 程序化音效（射击、爆炸、受击、道具、开始/结束）
- 中文 UI：开始游戏 / 分数 / 生命 / 再来一局 / 静音
- 竖屏手机与桌面自适应，游玩时阻止页面滚动
